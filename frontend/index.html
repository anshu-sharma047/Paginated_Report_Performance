      How the Analyzer Works
      5 Specialized Diagnostic Engines
      1. RDL Schema-Agnostic Parser:

      Extracts datasets, command texts, query parameters, report parameters, tablix hierarchies, and expressions across any RDL schema (2008, 2010, 2016, and modern Power BI).

      2. SQL AST & Sargability Engine:

      Uses sqlglot to parse queries into an Abstract Syntax Tree, detecting SELECT *, non-sargable functions (e.g. YEAR(Date) = 2026), missing WHERE clauses, and cartesian joins.

      3. Visual-to-Query Field Pruning:

      Cross-references every visual, group expression, and visibility condition to identify unused columns that inflate network payloads across the Gateway.

      4. Architecture & Subreport Hazards:

      Flags orphan/unused datasets and alerts on the critical N + 1 query hazard where subreports sit inside repeating row hierarchies.

      5. Expression Engine:

      Audits expressions for deep IIF nesting (depth ≥ 3) and repeated type conversions (CDate, CDbl).
